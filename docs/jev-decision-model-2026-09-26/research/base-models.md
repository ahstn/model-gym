# Candidate base models — 26 September 2026

**Bottom line:** run one encoder baseline, then MiniCPM5-2B, then Qwen3.5-4B; rent ≥80 GB only after a held-out improvement justifies a larger model. Parameter counts below distinguish *stored* weights from FLOP-relevant active/core weights; a 24 GB card pays for all resident weights and optimizer state, even when only a subset of experts fires. Context maxima are architectural, **not feasible training sequence lengths on a 3090**. [Sources: K2 appendix](https://huggingface.co/IFM/K2-Horizon-3.7B/raw/main/APPENDIX.md), [Gemma card](https://huggingface.co/google/gemma-4-12B-it/raw/main/README.md), [Qwen MoE card](https://huggingface.co/Qwen/Qwen3.6-35B-A3B/raw/main/README.md).

## Verified repo inventory and practical fit

All linked repositories below returned an accessible public HF API record except where expressly noted; counts labeled `API` are `safetensors.total` and can include multimodal encoders, auxiliary heads or tied-embedding conventions rather than exactly the card's language-core count. [HF model API](https://huggingface.co/docs/hub/api). Fit = **estimate** for short (≤2K) text sequences, batch 1, gradient checkpointing; activation/context, attention backend and optimizer can change this radically. BF16 weights alone cost ~1.86 GiB/billion parameters; Adam full FT generally needs ≥12–16 bytes/parameter plus activations [INFERENCE]. TRL/PEFT are training libraries, while vLLM/SGLang are **inference** engines; a serving claim does not establish trainer support. [TRL](https://huggingface.co/docs/trl/index), [PEFT](https://huggingface.co/docs/peft/index), [vLLM](https://docs.vllm.ai/en/latest/), [SGLang](https://docs.sglang.io/).

## Choice of 4 trials, cheapest first

1. **ModernBERT-large (~396M), full-FT reference**: train a question+candidate-descriptions cross-encoder/label scoring baseline with an explicit Noul/Score readout, rather than assume fixed five-class labels transfer. If latency/accuracy Pareto already satisfactory, stop. For multilingual requirements, substitute mmBERT-base; for English tight latency test Ettin-150M. [ModernBERT](https://huggingface.co/answerdotai/ModernBERT-large), [mmBERT](https://huggingface.co/blog/mmbert), [Ettin](https://huggingface.co/jhu-clsp/ettin-encoder-400m/raw/main/README.md). [INFERENCE design recommendation]
2. **MiniCPM5-2B, BF16 LoRA** on the 3090 with author's TRL/PEFT r16 recipe, initial max length 2048 and constrained typed response. Compare post-trained final against SFT-only variant if reasoning overhead harms latency. It is the least tooling-risk generative base with explicit recipe, 2.52B actual storage despite the name. [card](https://huggingface.co/openbmb/MiniCPM5-2B/raw/main/README.md), [recipe](https://raw.githubusercontent.com/OpenBMB/MiniCPM/main/docs/finetune/trl.md). [INFERENCE trial design]
3. **Qwen3.5-4B, 4-bit QLoRA** as leaderboard-anchored alternative; test 2K first, hold train/eval split identical. Its hybrid DeltaNet operator and multimodal overhead raise implementation risk vs MiniCPM, but Hopper/JevK5 provide a meaningful attainable benchmark. [Qwen card](https://huggingface.co/Qwen/Qwen3.5-4B/raw/main/README.md), [board](https://huggingface.co/spaces/multimodalart/jev-decision-index). [INFERENCE]
4. **Gemma 4 12B QLoRA on rented 80–96 GB** only if 2B/4B saturate below target and a same-protocol pilot demonstrates incremental benefit; 12B Winnow's older 45.0 is stronger practical evidence than an unproven custom K2 model despite K2's long-context headline. Alternatively use rented ≥80 GB for 26B-A4B if 12B fails and serving budget tolerates ~26B resident weights. [Gemma card](https://huggingface.co/google/gemma-4-12B-it/raw/main/README.md), [board](https://huggingface.co/spaces/multimodalart/jev-decision-index). [INFERENCE]

**K2 challenge:** “3.7B” is **3.78B core excluding 1.28B embedding/output weights**, thus **5.06B stored and active**. The older appendix mentions FP32 storage / `main=mid_4_final`, but live `config.json` reports BF16 and live README calls main post-RL/SFT; **documentation differs across revisions**, pin checkpoint and trust actual revision config before measuring. Its 512K context is irrelevant if training/evaluation typically fit 2K, while remote-code PEFT target validation is extra work. Run *inference-only* matched pilot before committing FT. [appendix](https://huggingface.co/IFM/K2-Horizon-3.7B/raw/main/APPENDIX.md), [current config](https://huggingface.co/IFM/K2-Horizon-3.7B/raw/main/config.json), [current card](https://huggingface.co/IFM/K2-Horizon-3.7B/raw/main/README.md).
