# IQA/IAA training evidence, checked 2026-11-17

Search conducted with the Exa plugin; official implementations inspected through the GitHub plugin. Findings are primary-source claims, not reproduced experiments. Dates below identify publication/release rather than treating crawl dates as publication dates. Contemporary VLM IQA evidence supports investigating RL, but does not justify making it the first training stage for our scalar teacher labels and $50 exploratory budget.

## Evidence matrix

| **Q-Align**, ICML 2024 | SFT on five ordinal text levels; expected score from their normalized probabilities. Directly compares discrete-level learning to score-text generation. | Strong task-specific baseline; no need for free-form reasoning. Five probabilities permit a continuous expectation, so a five-level head does not imply only five possible output scores. Original hard binning discards teacher precision. |

## Recommendation for our targets and evaluation

1. Train supervised teacher distillation first. Keep technical and aesthetic outcomes separate and retain accepted weights. A head or ordinal-token expectation removes numeric-text-token quirks; keep structured JSON as a deterministic API layer, or use short JSON-SFT as a deliberately simple comparison.
2. Start with LoRA, not full-model tuning. Fix which modules change. Language-only adapters cannot restore detail removed by preprocessing. Compare global-view input with one carefully specified global+detail view before escalating parameters.
3. A strong minimal objective is two independent Huber/MAE point targets (or two ordinal distributions whose expected values target the ensemble score), with eligibility tracked separately. A controlled secondary objective may rank sufficiently separated pairs. Absolute calibration still matters: rankings alone permit arbitrary score offsets/scales.
4. If using five ordinal bins and only scalar teacher means, linear interpolation into adjacent bins preserves the mean: e.g.,3.7→.3on3+.7on4. This is a target encoding, **not** a measured human rating distribution. DeQA explicitly discusses this as its near-zero-variance limit. Do not treat three correlated teacher scores' spread as human MOS variance or calibrated uncertainty. Study teacher disagreement separately for review/weights/ablation.
5. Use full precision targets; round at serialization. Two decimals in JSON is a presentation constraint, not a demand for 401 classes or proof of hundredth-point accuracy.
6. Hold out source families before embedding retrieval/pair construction; separate prompt/weight-tuning examples from fresh confirmation. Weight losses or sample so the large easy scope-floor population cannot dominate metrics. Keep eligible-photo and excluded-photo results separately. Evaluate each outcome MAE/bias/SRCC/large-error rate; poor, fair, high-quality, low-light intentional/unintentional, DOF vs globalblur, grain vs detail, artwork-context boundaries and aspect ratios. Use family-bootstrap CIs.
7. Derive technical monotonic pairs only after checking that controlled degradation actually worsens the delivered image. Aesthetic ordering is not guaranteed by blur/noise transforms. Avoid pair explosion and overcounting siblings as independent examples.
8. Do not learn long rationales from teacher text simply because it exists: grounding and contradiction tests are needed. Better scalar imitation does not independently validate visual correctness. RL against the same synthetic reward cannot establish human accuracy.
9. Reserve full tuning or RL for a failure established by a matched baseline: LoRA capacity limit; reliable human/verified pair preference gains; a valuable learned crop policy with actual trajectories. Standard score-label training does not require an environment or PPO machinery.

## Repo-level details worth preserving

- Q-ReAlign's code/config is a better starting point than copying original Q-Align's older backbone, but any new run requires exact checkpoint, processor, source and module freeze/adapter pins.
- DeQA LoRA's retained visual training and ranking losses matter; comparing it to language-only Qwen LoRA without these distinctions would conflate changes.
- RALI public training completeness is uncertain; ReLIQS released execution differs from its sparse top-k claims. Paper results and ready-to-run capabilities should be recorded separately.
- Evidence is stronger for technical IQA than broad aesthetics. ArtiMuse/PortraitAes offer relevant IAA approaches but different annotators/scales/domains. Our own held-out evaluation remains decisive.
