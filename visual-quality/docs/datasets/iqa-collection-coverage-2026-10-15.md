# IQA collection component audit — 2026-10-15

The collection exposes 31 supported loader entries. Fourteen have their own rows in the existing dataset inventory. BAPPS is mentioned as an upstream source but has no row. Sixteen entries are absent from the inventory; they represent 15 distinct datasets because CIDIQ_MOS50 and CIDIQ_MOS100 use the same images under different rating conditions.

These counts describe the inventory at the start of this review. LIVE-MD and MDID2013 are mentioned in a training evidence table, so they are not wholly unknown to the repository. PieAPP appears only in a saved search-result URL. Neither a URL nor a collection reference counts as a dataset inventory entry.

## Evidence for the most useful omissions

**CID2013 is the first compact omission to assess for independent camera-quality evidence.** The original Zenodo record reports 474 unique images, 79 devices, six image sets, 188 observers, and an extra 34-observer scale-alignment experiment. It includes MOS, sharpness, graininess, lightness, color saturation, and raw responses. Its laboratory display used 1600×1200 scaled images, so these scores do not validate unrestricted native-resolution viewing. The record carries CC BY 4.0 and a detailed notice permitting database use with attribution and notice retention. That notice requires permission for individual media use outside the database scope, such as marketing. Retain both forms of evidence. This is a small controlled-camera test, not a large source-diverse training pool. [Original record](https://zenodo.org/records/2647033)

**BIQ2021 is a useful general-photo lead, but label ingestion is blocked pending a mapping audit.** The [release comparison](candidate-review-2026-10-15.md#biq2021) found conflicting MOS values for byte-identical images across the author and Kaggle releases. Until that mismatch is resolved, do not use either release as trusted gold or merge their labels. The original README separates 2,000 personal captures made between 2007 and 2020, 2,000 deliberately altered camera captures, and 8,000 Unsplash photos. Thirty observers supply five-level ratings, released as MOS scaled to 0–1. It supplies a fixed 10,000/2,000 train/test split. A current root listing contains no LICENSE file. The author's general statement about Unsplash use is not per-image provenance for every item. Keep its subsets visible in metrics; do not let the stock-photo portion hide failure on poor captures. Check both repeated captures and online-photo overlap. [Author repository](https://github.com/nisarahmedrana/BIQ2021)

**CID:IQ offers a useful viewing-condition experiment.** Its original NTNU record lists 23 references, six distortion types, five levels, and 17 observers under CC BY 4.0. A paper coauthored by the dataset author confirms that its 690 images were rated at both 50 cm and 100 cm. This can probe whether a fixed scalar changes with presentation conditions. The two loader entries must share identity and split membership. It is not equivalent to varying digital resolution alone. [Original record](https://zenodo.org/records/17376246), [viewing-distance study](https://doi.org/10.1109/icip.2019.8803056)

**LIVE-MD or MDID2016 can test distortion interactions.** The pilot currently applies one of three operators per parent family. LIVE-MD tests blur followed by JPEG or noise. MDID2016 has 1,600 distorted images from 20 references, using random combinations and levels; it was published in Pattern Recognition in 2017 despite the loader name. Either offers a targeted stress test, not a reason to ingest every old synthetic dataset. Confirm media terms and reference overlap before use. [LIVE-MD release](https://live.ece.utexas.edu/research/Quality/live_multidistortedimage.html), [MDID paper](https://www.sciencedirect.com/science/article/abs/pii/S0031320316301911)

**PieAPP is useful for a separate reference-relative ranking task.** Its own dataset README gives 20,280 distorted images from 200 Waterloo references and 81,480 preference labels. The 160 train/validation references have both raw and model-estimated probabilities; the 40 test references use exhaustive comparisons with 40 judgments per pair. The task asks which distorted image is closer to its reference. It is not a direct statement of which unrelated photo is better. Its dataset terms explicitly restrict use to non-commercial education/research and retain photographer rights. [Dataset README](https://github.com/prashnani/PerceptualImageError/blob/master/dataset/dataset_README.md), [terms](https://raw.githubusercontent.com/prashnani/PerceptualImageError/master/dataset/TERMS_OF_USE.pdf)

GFIQA is a secondary option if portrait quality is central. BAPPS deserves its own inventory row, but its local reference-relative task should remain separate from MOS and aesthetics. These are more useful corrections than adding many small legacy distortion sets.

## Ranking against the existing pilot

1. Keep the current pilot audit ahead of acquisition: review the concentrated test group, obtain human quality/aesthetics labels and positive domain labels, freeze the viewing contract, and clear external overlap.
2. For new authentic camera evidence, inspect **CID2013 first**, then reconsider **BIQ2021** only after the reported conflicting labels, rights, and source provenance are resolved. Neither automatically outranks already documented CLIVE, KonIQ, SPAQ, or FLIVE for every use.
3. For specific blind spots, add **CID:IQ** for presentation sensitivity and **LIVE-MD or MDID2016** for compound distortions. Keep each as a separate diagnostic with reference-grouped splits.
4. Use **PieAPP/BAPPS** for reference-relative fidelity and **GFIQA/PIQ23** for portrait-specific quality. Do not combine their targets into the main scalar without a separate task definition.
5. Defer A57, TID2008, SDIVL, Toyama, PDAP-HDDS, and VCLFER unless a baseline protocol requires them. They do not address the pilot's main low-aesthetics or hard-domain gaps.

The collection adds no new aesthetics dataset beyond AVA and AADB, both already documented. It adds no direct document/screenshot/meme/photorealistic-origin eligibility dataset. It therefore cannot replace the planned low-aesthetics audit or hard-domain controls.

## Verification limits

The work used primary GitHub records, original laboratory pages, author repositories, publisher papers, and deposit records. It did not run the collection loader, download its image archives, or train models. A57 and Toyama source pages were unavailable; the MDID2013 paper was blocked. Their table facts are deliberately limited to the pinned collection. SDIVL/MDIVL initially failed over HTTPS but the official HTTP page returned content.
