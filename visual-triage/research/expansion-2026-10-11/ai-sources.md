# Additional photographic detection data

This review used five Exa queries in four rounds, with 35 requested results. The number counts requested results, not unique or verified sources. A fresh Hugging Face plugin search failed because its dataset search tool was unavailable. The public Hub and Dataset Viewer APIs supplied current metadata, source rows and images. No detector output guided acquisition.

| Source | Verified design and access | Decision |
| --- | --- | --- |
| [SynthCLIC](https://huggingface.co/datasets/marco-willi/synthclic) | 2,163 real photo groups, each with four generated counterparts; 10,815 rows. Public, not gated. [Author paper](https://arxiv.org/abs/2602.12381) describes caption matching with Imagen 3, SD3 Medium and two FLUX models. | Select a group-disjoint panel. Hold Imagen 3 out of training and development. |
| [Synthbuster](https://zenodo.org/records/10066460) through the [author-linked mirror](https://github.com/marco-willi/clip-cues) | Original nine generator outputs have CC-BY-NC-SA 4.0 terms; RAISE photos permit non-commercial research and education. Shared source IDs define caption families. | Select previously unseen native test families for an external source test. Exclude all families in prior acquisition and eligibility records. |
| [Community Forensics Eval](https://huggingface.co/datasets/OwensLab/CommunityForensics-Eval) | 51,836 rows from 21 generator models and paired real source datasets; public, not gated, CC-BY-NC-SA 4.0 for non-commercial research and education. Its card preserves model-specific terms. | Useful larger external benchmark. Per-image matching still needs verification. Do not assume that the smaller redistribution set has exact caption matches. |
| [Chameleon](https://github.com/shilinyan99/AIDE) | Academic research only; commercial use prohibited. The official README requires an email request for access. | Defer acquisition. An ordinary public release was not verified. |
| [DRCT-2M](https://github.com/beibuwandeluori/DRCT) | ModelScope release; text-generated outputs and reconstructed COCO images. The official paper covers 16 diffusion model types. The searched HF repository is empty. | Defer. The reviewed primary pages did not establish precise dataset terms or efficient paired access. |
| [GenImage](https://github.com/genimage-dataset/genimage) | About 2.68 million images, eight generators, ImageNet class matching. Official release links to Drive and Baidu. | Class matching is weaker than source-caption matching. ImageNet rights still apply; a mirror's licence claim does not replace them. |
| [DDA-COCO](https://huggingface.co/datasets/Junwei-Xi/DDA-COCO) | Author card says Apache 2.0 and describes VAE reconstruction plus frequency alignment of COCO validation photos. | Defer as a separate reconstruction stress test. These positives are not fully generated photographs. Original COCO image rights remain relevant. |

The [SynthCLIC card](https://huggingface.co/datasets/marco-willi/synthclic/blob/feff43b543929916bac097e30217cc3fdc09c32d/README.md) says only `license: cc`. That tag does not identify a complete licence. The authors state that release remains subject to underlying photograph terms. The primary CLIC sources identify [mobile photos as CC0](https://data.vision.ee.ethz.ch/cvl/clic/LICENSE_mobile_2020.txt) and [professional photos under the Unsplash licence](https://data.vision.ee.ethz.ch/cvl/clic/LICENSE_professional_2020.txt). The [official archive](https://archive.compression.cc/2021/tasks/index.html) links the professional CLIC2020 files and their terms. An [organiser statement](https://groups.google.com/g/clic-2020/c/pVCa3pH0nQk) confirms both licences. This research uses that source chain, not a presumed grant from the generic card tag. Image binaries stay outside version control.

The acquisition plan contains 80 training, 40 development, 40 final and 40 external pairs. Every pair has one real and one generated image. All source families stay in one split. Main source revision: `feff43b543929916bac097e30217cc3fdc09c32d`. External mirror revision: `dbfb72f1ee96e953ee5cff80c58832fe89e1d2b5`. The final native cohort limits main training candidates to the first 100 professional and first 100 mobile families and the first 125 main test families. The external cohort uses all 200 mirror native test families minus 111 reviewed prior IDs, with SDXL as its sole generator. This change was frozen before inference to meet the 3 GB acquisition limit. Photographic eligibility uses the prior medium rule and excludes a whole pair if either member is clear artwork or a render. Visible defects do not cause exclusion.

This design tests both generator and source transfer. It does not establish detection of current commercial models, production precision, or freedom from model pretraining exposure. Shared delivery transforms remove direct size and metadata cues, but source encoding histories can still differ. The initial Viewer acquisition was rate-limited. Selected bytes therefore come from native pinned parquet image columns, preserving embedded EXIF when present. This still does not prove that files are untouched camera originals.

Primary responses and licence files are retained in `visual-triage/evidence/ai-expansion/`. Failed and obsolete URLs remain recorded as failed checks. No correspondence was sent to request restricted data.
